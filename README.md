# holy-bot

Небольшой Telegram-бот на Go. После команды `/start` он присылает в чат случайные
изображения из локальной папки — файлы `bible-1.JPG` … `bible-516.JPG`. Между
отправками пауза задаётся в конфигурации.

Бот не связан с платформой HolyStaff: это отдельный небольшой проект для
показа библейских картинок в Telegram.

## Как работает

1. Пользователь отправляет `/start`.
2. Бот выбирает случайный номер от 1 до 516 и отправляет соответствующий JPG.
3. Ждёт `WAIT_TIME` секунд и повторяет, пока процесс не остановят.

При старте проверяется, что папка с картинками существует. Сами изображения в
репозиторий не входят — их нужно положить на диск отдельно.

## Сборка

```bash
go build -o bin/holy_bot -v .
```

## Настройка

Создайте файл `.env` в корне проекта (рядом с `main.go`):

```env
TOKEN=123456:ABC-DEF...
PICTURE_PATH=/path/to/images
WAIT_TIME=5
```

| Переменная     | Описание                                      |
|----------------|-----------------------------------------------|
| `TOKEN`        | Токен Telegram-бота от [@BotFather](https://t.me/BotFather) |
| `PICTURE_PATH` | Путь к каталогу с `bible-1.JPG` … `bible-516.JPG` |
| `WAIT_TIME`    | Пауза между отправками, в секундах            |

## Запуск

```bash
./bin/holy_bot
```

Запускайте из корня проекта, чтобы бот подхватил `.env`.
